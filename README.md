# EuroHPC-TVB-Digital-Twin: Personalized Brain Simulation Center

Welcome to the central workspace for our EuroHPC-based personalized brain simulation digital twin initiative. This project integrates research from Transconnectome I, specifically the **Diver project**, to scale personalized neuroimaging simulations onto world-class supercomputing infrastructure.

---

## 🚀 Quick Start & Onboarding
New to our workflow? Follow these steps to get started:

1. **Project Overview**: Understand our goal to leverage EuroHPC resources (Benchmark/Regular Access) for scaling TVB (The Virtual Brain) simulations.
2. **Setup**: Access the high-performance computing environment through the EuroHPC JU portal.
3. **Research Integration**: See the [Diver Project Documentation](docs/projects/diver/README.md) to understand how our core neuroscience research plugs into this infrastructure.
4. **Benchmarks**: Check the `/benchmarks` directory for current scalability evaluation tasks.

---

## 📊 EuroHPC Access Strategy
We are navigating a phased deployment to secure significant compute allocations:

| Phase | Path | Goal | Status |
| :--- | :--- | :--- | :--- |
| **P1** | **Benchmark** | Code scalability & performance tests | `In-Progress` |
| **P2** | **Development** | Optimization & Porting to Exascale | `Planned` |
| **P3** | **Regular** | Large-scale production runs (1M+ GPUh) | `Target` |

## 📂 Repository Structure
- `proposal/`: Drafts, templates, and submission logistics for EuroHPC calls.
- `benchmarks/`: Core kernels, scalability scripts, and performance logging.
- `gpu_hour_model/`: Models for estimating resource requirements.
- `scripts/`: Automation for experiment data collection.
- `docs/`: 
  - `eurohpc_application.md`: Centralized application guidelines.
  - `projects/`: Integration of specific lines like **Diver**.
