# Jirsa Collaboration Plan

## Objective
Establish collaboration with the TVB (The Virtual Brain) group to scale personalized whole-brain simulations using EuroHPC infrastructure.

## Scientific Integration
The collaboration will integrate:

- Whole-brain neural mass modeling (TVB)
- Subject-specific connectomes
- Large-scale parameter inference
- Population-level simulation

## Computational Goals
- Extend TVB to large-scale HPC environments
- Develop GPU-accelerated inference pipelines
- Enable digital twin simulations at population scale

## Strategic Value
This collaboration aligns with:

- EBRAINS infrastructure
- European digital brain initiatives
- Personalized medicine and psychiatry

## Expected Outcomes
- Scalable brain simulation pipeline
- Benchmark results for EuroHPC
- Joint publications
- Foundation for extreme-scale allocation proposals
